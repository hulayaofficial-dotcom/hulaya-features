# Hulaya Marketplace

Produktbasis für den Rebuild von **hulaya.com** (weg von Kreezalid) als Dance-only Marketplace für:
- Workshops
- Camps
- Events

## Dokumentation
Die vollständige Produkt- und Umsetzungsdokumentation liegt unter:

- [`docs/README.md`](docs/README.md)

## Phase-1 Ziel
Ein real launch-fähiger Marketplace mit:
- Discovery + Search + Map
- Listing-Detail + Variants
- Checkout + Promo Codes + Stripe Connect
- Dancer Area (Orders, Tickets, Wishlist)
- Organizer Area (Listings, Orders, Participants, Check-in, Analytics, Payouts)
- Basic Admin
