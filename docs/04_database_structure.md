# Document 4 — Database Structure

## Prinzip
Postgres + Supabase; einfach und produktionsfähig für Listings, Variants, Orders, QR, Check-in, Analytics, Promo, Payouts.

## Core Tables
- users
- organizers
- listings
- listing_variants
- wishlist_items
- promo_codes
- orders
- participants
- checkin_logs
- payouts
- messages (optional)
