# Document 3 — Page Specifications

## Homepage
Hero, Search, Category Cards, Featured Listings/Cities, Organizer CTA, About, Footer.

## Category/Search
Filterbar + Sorting + Grid + Map Toggle.
Filter: location, date range, style, level, price.

## Explore
Split view (list + map), clustered pins, quick preview, search this area.

## Listing Detail
Gallery, Title, Organizer, Badges, Date/Time, Map, Description, Refund Policy,
External Links, Variant Picker/Single Price, Availability, Book CTA, Wishlist.

## Organizer Store
Banner, Avatar/Logo, Bio, Links, aktive Listings.

## Dancer
Dashboard, Purchases (upcoming/past), Ticket Detail (QR + order/ticket data).

## Organizer
My Listings, Add/Edit Listing, Orders, Participants, Check-in, Analytics, Promo Codes.
